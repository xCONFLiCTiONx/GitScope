# Portfolio Privacy Policy

**Effective Date:** August 5, 2026

Portfolio is a modern, dynamic, and GitHub-centric portfolio template designed for software developers.

## 1. Data Collection
This portfolio template automatically fetches your profile information and popular repositories directly from the GitHub API. This interaction happens on the client-side (in the user's browser).

## 2. Privacy and Storage
No personal data is stored on a server by this template. All information fetched via the GitHub API is processed locally to generate the UI. No third-party tracking or analytics are included in the base template.

## 3. GitHub API
Usage of this template is subject to the GitHub Terms of Service and Privacy Policy regarding API usage.
